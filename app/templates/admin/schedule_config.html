How Schedules Work
  • Only active configs are shown to customers when booking.
  • The system uses the active config with the widest hours by default.
  • You can have different configs for different seasons (e.g., "Festive Early Birds 6–10 AM").
  • Slots are generated automatically — no manual slot creation needed.
